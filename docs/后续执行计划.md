## 2. 云端操作（重启实例后，按顺序执行）

### 任务 1：BERT 重跑（折中配置）

```bash
cd /mnt/workspace/NLP-News-Classification-Learning-Contest
git pull origin main          # 拉最新代码（含环境变量已在 bashrc，无需重复 export）

# 确保旧 checkpoint 已删（避免误续跑）
rm -f models/bert_checkpoint.pt

# 重跑：4万条 / 192长度 / 3 epoch（约1小时，分数预期0.80~0.88）
```
