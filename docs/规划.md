# 智慧笔迹：NLP 新闻分类学习赛 —— 项目规划

> 选题：天池「AI 入门系列」智慧笔迹 NLP 新闻分类学习赛
> 课程：大数据应用系统综合设计（2 周 2 学分）
> 仓库：NLP-News-Classification-Learning-Contest

## 一、课设认识

- 本质：用两周走完一条「数据 → 预处理 → 建模 → 评估 → 融合 → 可视化 → 演示」的 NLP 工程流水线，竞赛只是载体。
- 成绩权重：验收答辩 50% + 设计报告 35% + 平时 15%。**排名是加分项，不是及格线**。
- 拿分关键：能现场演示、能把模型讲清、报告里有「功能图 / 流程图 / 模型图 / 算法对比 / 性能迭代可视化 / 排名截图」。

## 二、硬时间节点

| 时间 | 动作 | 产出 |
|------|------|------|
| 第1周周一 | 组队报名、下载数据上传云班课 | 报名截图 |
| 第1周周五 | 测环境、填阶段检查单 | 检查单（平时15分） |

## 三、赛题要点（官方）

- 任务：14 类新闻文本多分类。
- 数据：训练 20w / 测试A 5w / 测试B 5w；**字符级匿名化**，空格分隔数字 token；`\t` 分隔，列 `label`+`text`。
- 评测：**macro F1**（`f1_score(..., average='macro')`）。
- 标签映射（官方固定）：

```python
label_map = {
    '科技': 0, '股票': 1, '体育': 2, '娱乐': 3, '时政': 4, '社会': 5, '教育': 6,
    '财经': 7, '家居': 8, '游戏': 9, '房产': 10, '时尚': 11, '彩票': 12, '星座': 13
}
```

## 四、技术路线（逐级上分）

| 阶段 | 方案 | 参考 macro F1 |
|------|------|------|
| baseline | TF-IDF + 逻辑回归 | ~0.88–0.90 |
| 进阶 | fastText（字符 n-gram） | ~0.91–0.92 |
| 深度学习 | Word2Vec + TextCNN | ~0.92–0.94 |
| 深度学习 | BiLSTM + Attention | ~0.93–0.95 |
| 预训练 | BERT 微调 | ~0.95–0.96 |
| 融合 | 多模型投票/加权 | ~0.96+ |

优化技巧：5折CV、FGM对抗训练、标签平滑、长度截断/分块池化、多模型集成。

## 五、两步走任务主线

- 主线A（第1周前半）：TF-IDF+LR 跑通全链路 + EDA（类别分布/长度分布/高频token），先拿第一个排名。
- 主线B（贯穿两周）：逐级建模，每模型产出「5折CV分数 + 训练曲线 + 预测概率」三样素材，拼成报告对比与迭代。
- 主线C（第2周）：Gradio 交互界面 + 答辩 demo + 报告6章。

## 七、风险与应对

- GPU 不足 → BERT 才需要 GPU，本地 CPU 先跑基线；AutoDL 无卡模式调试。
- 匿名化难下手 → 报告「难点分析」亮点；字符 n-gram + 自训练 Word2Vec 解决。
- 时间紧 → 边做边攒素材，不最后补。
- 答辩讲不清 → 每人提前备模型原理图 + 结果对比表，组内互讲。
